# Regulation source

File: `de-onsite-wastewater-2014.pdf`

Title as published: Delaware On-Site Septic System Regulations with Exhibits,
January 11, 2014. The document's own title page reads "Regulations Governing the
Design, Installation and Operation of On-Site Wastewater Treatment and Disposal
Systems", issued by the Department of Natural Resources and Environmental
Control, Division of Water, Groundwater Discharges Section, under statutory
authority 7 Del.C. Chapter 60.

Provided by a DNREC mentor as the governing regulation for this work. The same
mentor scoped the permit corpus to 2014 onward, because permits from 2014 forward
fall under this document and earlier permits fall under superseded law.

Length: 245 pages including exhibits. The file has an embedded text layer, so
section text is read directly with pdfplumber and no OCR is required.

This file is the only authority for threshold values in the rule set. Candidate
passages extracted from it are listed in `src/septic/rules/candidates.md` with
section, page, and a verbatim quote. A value moves into
`src/septic/rules/rules_7101.yaml` only after a person opens the cited page and
confirms it.

The original filename was
`delaware-on-site-Septic System regulations-with-exhibits (Jan. 11, 2014).pdf`.
It was renamed for a stable path without spaces. The bytes are unmodified.
